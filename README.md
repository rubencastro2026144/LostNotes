# LostNotes

Projeto final de **Sistema de Gestão de Conteúdos**: loja de discos de vinil em WordPress (LocalWP, tema Twenty Twenty-Five, WooCommerce).

O site é construído no **editor do WordPress**. Este repositório guarda o planeamento, os guias de cada passo, o código colado no editor e a base da nota técnica.

## Estrutura

| Pasta / ficheiro | Conteúdo |
|---|---|
| `docs/01-planeamento.md` | Objetivo, público, mapa do site, identidade visual (R01) |
| `docs/02-passo1-interface-base.md` | Guia do passo 1: páginas, estilos, menu, página inicial |
| `blocos/` | Código de blocos para colar no **Editor de código** do WordPress |
| `css/lostnotes.css` | CSS adicional (R07), colado em Estilos → CSS adicional |
